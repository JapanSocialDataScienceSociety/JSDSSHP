## 過去の履歴を確認するには

本学会の規約改訂や役員選任などの変遷を辿るには、GitHubの **History（履歴）** 機能をご活用ください。

1.  リポジトリ上部のファイル一覧にある `History` ボタンをクリック。
2.  各コミット（保存記録）を選択することで、いつ、どの項目が変更されたかを詳細に確認できます。
